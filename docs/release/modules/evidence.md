# Evidence

`emergence_evidence` owns compact reducers and campaign/world atlas projections.

Example: `python -m engine.campaigns.paired_cpu_usage_v1 --help` describes the authenticated read-only CPU pair comparison. It delegates analysis to the existing campaign analyzer and verifies source, controls, seeds, coverage and checkpoint comparisons. The world-atlas reducer in the separate growth-base declaration remains unexecuted in this release workflow.

Evidence is read-only analysis of sealed observations; it does not grant execution or Qualification. Native reducer build inputs are shipped. Keep retained claims within observable fields.

Dependencies follow [the source map](../source-to-module.json) and the existing ten-module DAG. Shared legacy imports remain under the unchanged debt ratchet.

Important checks: Reducer contract tests, original compact/native reducer regressions, and installed paired run output when available.

Status: Retained advanced capability. Canopy is a checkpoint projection unless complete lifecycle events are proved.

Evidence Manager has no implicit machine-specific evidence directory. Pass
`discover --root PATH` or `assess --evidence-root PATH`, or set the absolute
`EIEL_EVIDENCE_ROOT` environment variable. Command-line roots take precedence;
relative command-line paths remain relative to the current working directory.
`assess --out-dir PATH` selects the report destination directly and does not
require an evidence root. Missing configuration fails before report generation.
Configuration does not authorize mutation of retained scientific evidence.
