# Public source boundary

This is a fresh source snapshot with unrelated Git ancestry. The historical
research repository, operational records, qualifications and private evidence
are not incorporated into its Git history. Source manifests identify the
contents of this snapshot; source code alone is not an archived experiment.

Kept: ecological worlds, agent policies and genetics, mutation/selection code,
CPU and optional native/GPU implementation source, typed contracts, campaign
compilation and canonical execution APIs, checkpoint/evidence/lifecycle guards,
portable examples, meaningful synthetic tests and curated documentation.

Omitted: historical operator reports and custody projections, machine-specific
campaigns and launch helpers, host service definitions, private review packets,
unavailable migration records, and dependent historical analysis/test programs.
Static dependency closure was checked before sealing the snapshot. Omitted
historical functionality has not been replaced with a toy simulator. Advanced
source that remains is not thereby validated for execution on a new machine.

Runtime location defaults now use the existing `engine.runtime_roots` resolver.
`EIEL_RUNTIME_ROOT` selects a user-owned absolute root; the default is the current
user's `.local/share/emergence`. `EIEL_ARTIFACT_ROOT` selects a separate artifact
root when required. Known consumers obtain their runtime subpaths through that
same resolver. Set configuration before importing modules with cached defaults.
The storage template is authenticated before binding concrete paths. Its reserve
limits, explicit artifact inventory requirements, process/consumer protection,
and exact-root retirement rules remain in force. Canonical legacy reconstruction
is retained; missing original evidence does not become permission to delete it.

Compile-only campaign fixtures use synthetic, intentionally unavailable artifact
locators. They exercise schema, identity and rejection behavior; they are not
launchable historical campaigns. Security tests retain fictional personal-path
and conversation-URL negative controls. Exact file hashes, rules, lines and
rationales are recorded in `tools/release/privacy-exceptions.json`.

The TW-RNGV2 contract's private audit locator was removed from the public contract
view. Its content hash and dependent contract identity therefore change. The
algorithmic fields and arithmetic are preserved, but historical checkpoints or
qualification receipts must not be assumed compatible with this public identity.
The six retained `_artifacts` resources are source-consumed architecture/validation
contracts and a qualification-impact golden document; they are not supplied as
fresh performance evidence or a Qualification grant.

The public snapshot excludes embedded images, office documents, PDFs, archives,
compiled extensions, runtime databases and third-party datasets. Native sources
are included with the upstream terms in THIRD_PARTY_NOTICES.md. The file manifest
records each actual public file and its attribution scope.

## Qualification impact

Existing qualification preserved: historical source and evidence remain untouched privately.
Existing qualification invalidated: none in the historical repository.
New capability requiring qualification: public portability/packaging and any future qualified runtime claim against this snapshot.
Delta qualification performed: not performed; engineering validation only.
Qualification inherited: none for this distribution.
Representative sentinels used: component/import checks, packaging, representative CPU regressions, native paired run and exact continuations, storage retirement and privacy checks.
Remaining targeted qualification: any claimed GPU, Full Evolution, long-horizon or historical-state compatibility capability.
Broad requalification required: no.
Reason: this work makes a bounded source distribution; it neither changes private qualified records nor grants authority to the new snapshot.
